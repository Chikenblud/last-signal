# The Last Signal: Zero Hour

A browser survival game by Chiken. Hold out for twenty minutes, collect upgrades, and turn scavenged weapons into an arsenal. Movement is manual; weapons aim and fire automatically.

## Play

Open `index.html` in a modern desktop browser and select **Begin Transmission**. No installation, server, or external assets are required. A keyboard is required.

| Action | Controls |
| --- | --- |
| Move | WASD or arrow keys |
| Choose an upgrade | Click a card or press 1, 2, or 3 |
| Pause / resume | Escape or P |
| Mute / unmute | M |
| Restart after a run | R |

## Project history

This initial source is the existing standalone build from August 21, 2026, including rare power drops and weapon music layers. The game source has been preserved unchanged.

The portfolio repository also contains a copy at `last-signal.html`, displayed inside `play.html`. When releasing a game update, update both this repository's `index.html` and the portfolio's `last-signal.html` so the playable version matches.
